# HEROES OF REDFOX

Интерактивное меню выбора уровней RedFox в стилистике Heroes of Might and Magic III.

## Подключение

Вставьте в поле «Название игры» или HTML-заголовок игры RedFox:

    <script src="https://cdn.jsdelivr.net/gh/RedLine142/heroes-of-redfox@main/heroes-map.js"></script>

Скрипт автоматически подключает соседний файл `heroes-map.css`.

## Файлы
- `heroes-map.js` — разметка, интерактивные области и ссылки.
- `heroes-map.css` — оформление в стиле фэнтези-карты.
- `README.md` — инструкция по подключению.

## Координаты
Координаты активных областей заданы в системе 1280 × 850 и масштабируются вместе с изображением.

| Область | X1,Y1 — X2,Y2 | Уровень |
|---|---:|---:|
| Герой | 640,420 — 740,480 | 9049 |
| Замок | 530,222 — 725,370 | 9050 |
| Подземелье | 1100,340 — 1240,470 | 9051 |
| Верфь | 950,550 — 1170,700 | 9052 |
| Золотая шахта | 140,100 — 330,215 | 9053 |
| Склеп | 1020,180 — 1140,270 | 9054 |
| Лесопилка | 700,70 — 880,160 | 9055 |
| Противник | 60,730 — 150,820 | 9056 |
| Разведка | 16,545 — 60,670 | 9057 |

Ссылки ведут на `/play/safari/ID` внутри RedFox.

## Настройка
В начале `heroes-map.js` находится массив `LOCATIONS`. Для изменения названия, координат или ссылки редактируйте соответствующий объект. Размер исходной системы координат задаётся константами `MAP_WIDTH` и `MAP_HEIGHT`.
